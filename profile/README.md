# 42 Clubs

**42 교육생을 위한 동아리 정보 및 운영 관리 플랫폼**

42 Clubs는 42 내 동아리와 소모임의 정보를 한곳에서 확인하고, 동아리장과 운영진이 동아리 정보를 효율적으로 관리할 수 있도록 돕는 웹 서비스입니다.

## 📌 Project Overview

42에는 다양한 동아리와 소모임이 운영되고 있지만, 교육생이 현재 운영 중인 동아리를 탐색하거나 최신 모집 정보를 확인하기 위해서는 여러 채널을 확인하거나 관계자에게 직접 문의해야 하는 경우가 있습니다.

또한 동아리 정보의 갱신과 운영 현황 관리가 여러 채널에 분산되어 있어 최신 정보를 유지하고 확인하는 데 불편함이 발생합니다.

42 Clubs는 이러한 문제를 해결하기 위해 **교육생을 위한 동아리 탐색 공간**과 **동아리장 및 운영진을 위한 관리 공간**을 제공합니다.

## 🎯 Project Goals

- **정보 접근성 개선** — 교육생이 운영 중인 동아리와 활동 및 모집 정보를 한곳에서 확인할 수 있도록 합니다.
- **동아리 자율 관리** — 동아리장이 직접 소개, 활동 내역, 모집 정보 등을 관리할 수 있도록 합니다.
- **운영 효율화** — 운영진이 전체 동아리의 현황과 관리 권한을 통합적으로 관리할 수 있도록 합니다.

## ✨ Key Features

### 👨‍🎓 교육생 — 동아리 탐색

- 운영 중인 동아리 및 소모임 목록 조회
- 동아리 소개 및 주요 활동 확인
- 최근 활동 내역 및 공지사항 확인
- 동아리 활동 상태 및 신규 부원 모집 여부 확인
- 모집 기간 및 지원 방법 확인

### 🧑‍💼 동아리장 — 동아리 정보 관리

- 동아리 소개 및 기본 정보 수정
- 최근 활동 내역 등록
- 신규 부원 모집 상태 및 지원 방법 관리
- 동아리 공지사항 작성 및 수정

### 🛠️ 운영진 — 전체 동아리 관리

- 동아리 생성 및 운영 상태 관리
- 동아리장 관리 권한 부여
- 전체 동아리 현황 조회
- 등록된 동아리 정보 검토

## 🚀 Future Plans

초기 버전에서는 동아리 정보 제공과 기본적인 관리 기능에 집중합니다.

이후 실제 운영 과정에서 필요성이 확인된 기능을 단계적으로 확장할 계획입니다.

1. 실제 운영 데이터 이전
2. 운영 안정화 및 정식 서비스 전환
3. Google Form을 대체하는 활동 보고/설문
    1. 운영진 검토/승인 workflow 구현
4. 활동사진 AI 안면 인식
5. 익명 활동, 임시 게시글 기능
